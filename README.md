# LinguaTrade – платформа заказа переводов

Курсовой проект: веб-сервис, на котором клиенты размещают заказы на перевод
текстов и документов, а переводчики откликаются на них и выполняют работу.

- `backendfinal` – серверная часть: Node.js, Express 5, Prisma (PostgreSQL),
  JWT-аутентификация, загрузка файлов (multer), PDF-отчёты (pdfkit);
- `frontendfinal` – клиентская часть: React 19, React Router, Vite;
- `backendweb`, `backendweb2`, `frontendweb`, `frontendweb1` – промежуточные
  версии проекта.

## Запуск

```bash
# сервер
cd backendfinal
cp ../.env.example .env        # указать DATABASE_URL и JWT_SECRET
npm install
npm run db:deploy && npm run db:seed
npm run dev                    # http://localhost:4000

# клиент
cd ../frontendfinal
npm install
npm run dev                    # http://localhost:5173
```
